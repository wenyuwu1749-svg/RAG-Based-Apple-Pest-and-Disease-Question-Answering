Web import replaces only the web part of the corpus, keeps PDF text and invalidates the old vector index; archived files are unchanged. The main region of each HTML page is parsed; PDFs are imported above; special pages, tables and extracted text still need review.

Building the index sends the corpus to the configured embedding service. Standard and token-efficient RAG share this index.
